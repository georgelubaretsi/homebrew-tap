# homebrew-tap

Homebrew formulae for George Lubaretsi's command-line tools.

```sh
brew install georgelubaretsi/tap/gh-touchid
```

| Formula | What it is |
|---|---|
| [gh-touchid](https://github.com/georgelubaretsi/gh-touchid) | Touch ID-gated GitHub access for you and your agents on macOS |

Each tool's release job writes its formula here; changes to a formula go through the tool's own repository.
